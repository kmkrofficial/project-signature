# `public/` — Static Assets

This directory contains static files served directly by Next.js at the web root (`/`).

## Contents

- **`next.svg`**, **`vercel.svg`**: Framework logos.
- **`file.svg`**, **`globe.svg`**, **`window.svg`**: Vector icons for public presentation.
- Any custom favicon, robots.txt, or social share images placed here are accessible at `http://localhost:3000/<filename>`.
