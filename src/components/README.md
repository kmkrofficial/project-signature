# `src/components/` — Modular React Components

This directory contains modular React components organized by functional domain.

## Subdirectories

| Directory | Purpose |
| :--- | :--- |
| [**admin/**](./admin/README.md) | Security guards and authentication wrappers for the Admin Studio. |
| [**blog/**](./blog/README.md) | Reader ergonomics: syntax highlighter, reading progress bar, search palette, and sticky Table of Contents. |
| [**features/**](./features/README.md) | Interactive modals and dialogs (e.g., social links, contact forms). |
| [**layout/**](./layout/README.md) | Application chrome: persistent Header, Footer, AppShell, ThemeProvider, and grid containers. |
| [**providers/**](./providers/README.md) | Third-party SDK initializers and context bridges (Firebase Analytics). |
| [**ui/**](./ui/README.md) | General-purpose atomic UI components (Toast notifications). |
