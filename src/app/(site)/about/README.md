# `src/app/about/` — Professional Showcase Route

This directory implements the `/about` route, serving as the portfolio and career overview for Keerthi Raajan.

## Key Files

- **`page.tsx`**: Server component rendering:
  - **Executive Bio**: Professional title, location, direct contact action, and introductory paragraphs.
  - **Selected Projects**: Curated technical projects featuring direct GitHub links and technology stacks.
  - **Work Experience**: Interactive career timeline detailing professional milestones and achievements.
  - **Skills & Technologies**: Grid displaying programming languages, frameworks, and cloud tooling.
  - **Education & Publications**: Academic background and research papers.

## Dependencies

- Uses `PORTFOLIO_CONFIG` from `@/lib/portfolio-config` as the source of truth for portfolio data.
