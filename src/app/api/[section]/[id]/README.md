# `src/app/api/[section]/[id]/` — Single Item API Endpoint

This directory implements item-level CRUD at `/api/:section/:id`.

## Key Files

- **`route.ts`**:
  - `GET`: Fetches a single item by `section` and `id`.
  - `PUT`: Updates an existing item.
  - `DELETE`: Removes an item from the specified section.
